# Reference: backend API surface (client)

Typed wrappers live in `app/lib/core/api/backend_api.dart`. Base URL: `Env.apiBase` (default `https://api.360ghar.com/api/v1`). Auth: Supabase JWT on Dio.

Source of truth for the wire contract: the backend's `docs/openapi.json` and `contract-audit/contract-changelog.md`. Do not invent endpoints not listed here without product confirmation.

## Rules every call follows

- **Typed responses.** Each response is parsed into a DTO in `core/models/api_dtos.dart`. A missing required field throws `ApiException` with code `BAD_RESPONSE`. This covers `has_more` on a page, `status` and `visibility` on a tour, `type` and `is_active` on a hotspot, `status` and `progress` on a job. A field the schema marks optional keeps a default. `GET /tours/{id}` returns the owner shape or the public shape (no `user_id`, public scenes); `TourDetailDto` reads both.
- **Errors.** Every failure is an `ApiException` (`core/api/api_exception.dart`) read from `{"error": {"code", "message", "details"}}`. A 422 lists `details.fields[]` (`field`, `msg`, `type`). `Retry-After` is kept. Branch on `code`, never on `message`. Use `describeError(e)` for text shown to the user or stored in a job.
- **Lists** are `CursorPage` (`items`, `next_cursor`, `has_more`, `limit`, `total`). `getHotspots` and `getFloorPlans` send `limit=100` and follow `next_cursor` until `has_more` is false.
- **Request bodies** carry only keys the OpenAPI request schema declares (an unknown key is a 422). PATCH sends only the keys that change. `test/contract/backend_api_test.dart` checks declared and required keys of every body.
- **Enums** come from `core/models/wire_enums.dart`, generated by `tool/gen_enums.py` from `contract-audit/enums.json`. An unknown wire value reads as null (logged), never as a real value.
- **Creates** (`createTour`, `createScene`) take an `idempotencyKey` and send it as `Idempotency-Key`. The queue passes the same key on every retry. The backend declares the header only on `POST /bookings`, so tours and scenes ignore it today.
- **Names** (tour, scene, hotspot titles) are cut to 255 characters (`clampName`).
- **Deletes** return 204 with no body. There is no `success` key.

## Tours

| Method | HTTP | Returns |
|--------|------|---------|
| `createTour` | `POST /tours` (`title`, `description`, `visibility: unlisted`) | `TourDto` |
| `getTour` | `GET /tours/{id}` | `TourDetailDto` (`main_scene_id`, `scenes`, `floor_plans`) |
| `publishTour` | `POST /tours/{id}/publish` | `TourDto` (`short_code`) |
| `deleteTour` | `DELETE /tours/{id}` | none |
| `getAnalytics` | `GET /tours/{id}/analytics` | `TourAnalyticsDto` |
| `getQrCode` | `GET /tours/{id}/qr-code` | PNG bytes |
| `getFloorPlans` | `GET /tours/{id}/floor-plans` (all pages) | `List<FloorPlanDto>` |

## Scenes and hotspots

| Method | HTTP | Returns |
|--------|------|---------|
| `createScene` | `POST /tours/{tourId}/scenes` (`image_url`, `title`; no `order_index`) | `SceneDto` |
| `deleteScene` | `DELETE /scenes/{id}` | none (the server removes hotspots that point at it) |
| `createHotspot` | `POST /scenes/{sceneId}/hotspots` (navigation) | `HotspotDto` |
| `updateHotspot` | `PATCH /hotspots/{id}` (`target_scene_id`, `title`); navigation hotspots only, the editor compares the answer's `target_scene_id` with the chosen scene | `HotspotDto` |
| `getHotspots` | `GET /scenes/{sceneId}/hotspots` (all pages) | `List<HotspotDto>` |
| `deleteHotspot` | `DELETE /hotspots/{id}` | none |
| `requestCloudStitch` | `POST /scenes/{sceneId}/stitch` body `{ frame_urls }` (202) | `AiJobSnapshotDto` |

## Uploads

| Method | HTTP / behavior |
|--------|-----------------|
| `createPresignedUpload` | `POST /upload/presigned` with `folder_type: tour_original`, `tour_id`, required `file_size`. Returns `PresignedUploadDto` (every field required). |
| `uploadToCloudinary` | multipart POST to `signed_url` **without** the app Authorization header. Fields: `api_key`, `signature`, `timestamp`, `public_id`, and `type` only when the backend returns it. |
| `confirmUpload` | `POST /upload/confirm/{uploadId}` returns `UploadConfirmDto`. 503 `STORAGE_LOOKUP_FAILED` is retried after `Retry-After`; 400 `UPLOAD_SIZE_MISMATCH` and 404 `UPLOAD_NOT_IN_STORAGE` are terminal. |

## Not used by this client

The app has no WebSocket client, does not call `/capture-sessions`, and does not post viewer events. Share links use `Env.apiRoot` (`/v/{short_code}`), not `apiBase`. `apiRoot` is `API_ROOT` when set, else `API_BASE` without `/api/v1`. The backend sends no `share_url` or `embed_code`.
